# HR Analytics Dashboard | Power BI End-to-End Project

## Overview

This project demonstrates an end-to-end HR Analytics solution built using Power BI, covering data modeling, DAX calculations, report development, and dashboard deployment using Power BI Service.

The goal of this project is to transform raw HR data into actionable business insights related to workforce distribution, salary trends, leave balance, qualification impact, and organizational growth.

This project follows a complete Power BI workflow:

Power BI Desktop → Data Modeling → DAX Measures → Report Development → Power BI Service → Dashboard Creation

---

## Project Objectives

- Analyze workforce headcount across different job roles
- Identify salary distribution and top earners by job title
- Understand the relationship between employee qualification and salary
- Analyze leave balance to identify potential employee fatigue risk
- Track employee growth trends using Running Headcount
- Build interactive dashboards for business decision-making

## Deployment

The report was developed using **Power BI Desktop** and successfully published to **Power BI Service**.  
An executive-level dashboard was created in Power BI Service to enable centralized workforce monitoring, interactive analysis, and cloud-based business intelligence reporting.

This deployment demonstrates the complete Power BI workflow, including report development, cloud publishing, and dashboard creation for organizational decision-making.
